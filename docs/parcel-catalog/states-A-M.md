# Free statewide parcel data: AL through MO (25 states)

Phase 0 research, compiled 2026-11-15. Not legal advice.

**Method and limits.** All findings come from web-search result snippets. WebFetch and curl could not reach any of these hosts from the sandbox, so I could not open a REST `?f=pjson` field list, a download page or a license page directly. When a snippet named a field (for example `ownername` or `totalvalue`), the table says so. When it did not, the field is tagged LIKELY or UNKNOWN. Confidence tags:

- **VERIFIED**: a search result from the official publisher (a REST service page, metadata page or agency page) describes the dataset and its fields.
- **LIKELY**: the source is secondary, or the answer is inferred, or the official snippet was cut off before the detail.
- **UNKNOWN**: nothing found.

For the "county-by-county" rows, absence can't be proven by search. LIKELY there means no official statewide product turned up after several searches.

**Commercial-use caveat for all states.** Very few of these sources state an explicit license. Only Connecticut (CC0) and Minnesota (access constraint "None") have explicit open terms. Elsewhere, "free" means no fee, not a license that permits commercial use or resale. For a judgment-buying business, read each state's disclaimer before ingesting the data. The biggest red flag found is Indiana's statute on releasing names and addresses (see the Indiana row).

## Pricing notes for the county-by-county states

- ReportAll statewide snapshots seen in search results: CA $6,000; IL $6,000; IA $6,000; MI $7,000; GA $9,000 (TX $7,000 for reference). Single counties are usually $200-$400. Volume discounts are advertised. These are cached snapshots; check the live store.
- Regrid sells every state through its Data Store, with the price shown per state at checkout. I didn't capture current state prices. Historical self-serve county prices were about $100 for a CSV and $200 for a shapefile, both before 2023. Bulk and API licenses are quoted by sales, and **Regrid's license terms on resale and redistribution need review**.
- Land Records (landrecords.us) offers a hosted API at about $200/mo, plus one-time downloads. Its comparison page cites state prices of $900-$9,000, but that figure is unverified.
