# Free debtor-name sources: live verification (2026-11-25)

Scope: the six layer gaps in the brief, excluding sources already registered in `config/liens`, `config/person_lists` and `config/licenses` (for example `tx.harris.*`, `ca.ftb/cdtfa`, `de.revenue`, `ne.dor`, `vt.tax`, `nm.valencia`, `la.shreveport`, `la.nola.code_hearing_judgments`, `mo.st_louis_county.post_third_sale`, `az.tucson.code_liens`).

Method: every row below was fetched from this container on 2026-11-25. For an ArcGIS layer the check covered layer JSON, `returnCountOnly`, two sample rows, `editingInfo.lastEditDate` and the AGOL item `licenseInfo`. For a Socrata dataset it covered `/api/views/<id>.json`, `count(*)` and two rows. For a file it covered an HTTP GET (status, Last-Modified), PDF text extraction and a row count. Every host's `/robots.txt` was checked with Python `robotparser` against the exact path. No logins, tokens, search forms or challenge pages were used.

Column key:
- **Rows** is exact for APIs. For PDFs it is an approximate count of record lines.
- **Updated** is the data or layer edit date, or the file's Last-Modified.
- **robots**: `allow` means a robots.txt was fetched and permits the path, or the host answers 404, which means no rules. `403-AGOL*` means `services*.arcgis.com/robots.txt` answers HTTP 403 "Invalid URL". Under the brief's strict rule that is a **disallow**. The repo's existing configs (for example `mi.kalamazoo.*`, `ms.harrison.*`, `ga.albany.*`) treat the same 403 as "RFC 9309: 4xx = no rules, allowed". Those rows are marked VERIFIED FREE* so the owner can choose which rule to apply.

## Notes for adapter work

- **Phoenix evictions** is the strongest new layer. It holds defendant names and addresses, a monetary-judgment amount and the prevailing party, on an ArcGIS MapServer whose robots.txt is a 404 (no rules). The layer holds only about two months of filings, so snapshot it on a schedule to build history.
- **AL ADOR transcripts** cover all 67 counties with the same layout (`WWW_TRANS_01..NN.PDF`, 01 = Jefferson). **NM TRD auction ads** are also statewide. Both are refreshed by the state and parse with `pdftotext -layout`.
- **Clark NV, Jefferson KY, King WA, Atlantic City NJ and Honolulu** are annual statutory publications. The URL changes each cycle, so an adapter should start from the index page, not the file URL.
- **SD's report filename changes on every update.** Discover it from https://dor.sd.gov/businesses/taxes/.
- **RI is behind Cloudflare.** It served the table to Python urllib, but curl got a JS challenge, which was not bypassed. Treat RI as fragile.
- **The `403-AGOL*` rows** are a policy decision for the owner, since this repo already accepts the same 403 elsewhere.
